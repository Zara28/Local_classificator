# Локальный классификатор текстовых заявок (ТЗ)

## Описание задачи
Разработка легковесной модели машинного обучения для классификации входящих текстовых технических заданий (ТЗ) по 5 категориям: «Веб-разработка», «Мобильное приложение», «Дизайн», «Аналитика», «Маркетинг».

## Логика решения
Для решения задачи выбран гибридный подход, сочетающий современные методы обработки естественного языка (NLP) и алгоритмы классического машинного обучения. Это позволяет получить высокое качество классификации при сохранении высокой скорости работы и низких требований к вычислительным ресурсам (модель легко запускается локально без GPU).

## Алгоритм работы
1. **Подготовка датасета:** Сгенерирован синтетический датасет (`test_dataset.csv`), содержащий 50 примеров ТЗ (по 10 на каждую категорию). Примеры варьируются от формальных до размытых, чтобы модель училась на приближенных к реальности данных.
2. **Векторизация текста (Эмбеддинги):** Входящий текст пропускается через легковесную предобученную нейросеть `cointegrated/rubert-tiny2` (библиотека `sentence-transformers`). Эта модель оптимизирована для русского языка и переводит предложения в семантические векторы, сохраняя их смысловой контекст.
3. **Обучение классификатора:** Полученные векторы (эмбеддинги) передаются на вход модели логистической регрессии (`LogisticRegression` из `scikit-learn`). Алгоритм находит разделяющие гиперплоскости между 5 классами. Логистическая регрессия выбрана из-за устойчивости к переобучению на малых объемах данных и возможности выдавать вероятностную оценку (confidence score).
4. **Инференс (Предсказание):** При поступлении нового запроса алгоритм повторяет процесс векторизации и передает данные в обученный классификатор, возвращая наиболее вероятную категорию и процент уверенности.
